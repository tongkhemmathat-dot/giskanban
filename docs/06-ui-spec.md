**กฎการแสดงผล**
1. แสดง progress bar เฉพาะเมื่อมีขั้นตอน ≥ 1 ข้อ
2. ครบ 100% → bar เปลี่ยนเป็นสีเขียว
3. จุดสีซ้ายล่าง = priority
4. hover → เงาเข้มขึ้น + ขอบ indigo
5. คลิกที่ไหนก็ได้ → เปิด modal

## 5. Modal รายละเอียด (2 คอลัมน์)

**ซ้าย (2/3)**
1. ชื่องาน — แก้ไข inline
2. รายละเอียด — textarea
3. **✅ ขั้นตอนการทำงาน** ← ส่วนสำคัญที่สุด
4. 💬 ความคิดเห็น
5. 📎 ไฟล์แนบ

**ขวา (1/3) — พื้นเทา**
1. **✍️ ผู้สร้างใบงาน** (กล่องขาวเด่น อ่านอย่างเดียว)
2. ผู้รับผิดชอบ + ปุ่ม "✋ รับงานนี้" / "↩ ถอนตัว"
3. ความสำคัญ (dropdown)
4. กำหนดเสร็จ · SLA · Site · Device · ลูกค้า · เลขโครงการ
5. ⏱ บันทึกเวลา
6. 📜 Activity 5 รายการล่าสุด
7. 🗑 ลบใบงาน

## 6. บล็อกขั้นตอนย่อย ★

```text
✅ ขั้นตอนการทำงาน   3/11 · 27%        [＋ ใช้แม่แบบ ▾]
██████░░░░░░░░░░░░░░░░░░░░░░░░
⠿ 1. ☑ แจ้งผู้ใช้งาน + ขอ downtime window      โดย สมชาย ก.
⠿ 2. ☑ ตรวจ release note / compatibility      โดย ณัฐพล ว.
⠿ 3. ☑ ทำ backup ฐานข้อมูล + config           โดย ณัฐพล ว.
⠿ 4. ☐ ทำ snapshot เครื่อง (rollback point)   [ณัฐพล ว.▾] 🗑
⠿ 5. ☐ ติดตั้งเวอร์ชัน 12.1
[ พิมพ์ขั้นตอนแล้วกด Enter · วางหลายบรรทัดพร้อมกันได้ ]  [เพิ่ม]
```

**พฤติกรรม**

| การกระทำ | ผลลัพธ์ |
|---|---|
| กด `Enter` | เพิ่มขั้นตอน (Shift+Enter = ขึ้นบรรทัดใหม่) |
| วางข้อความหลายบรรทัด | สร้างหลายขั้นพร้อมกัน ตัดเลขนำหน้าอัตโนมัติ |
| ดับเบิลคลิกที่ข้อความ | แก้ไข inline |
| ลากไอคอน `⠿` | สลับลำดับ |
| hover ที่แถว | โผล่ dropdown ผู้ทำ + ปุ่มลบ |
| ติ๊กเสร็จ | ขีดฆ่า + สีจาง + แสดง "โดย <ชื่อ>" |
| เลือกแม่แบบ | ต่อท้าย + toast แจ้งจำนวน |

## 7. ฟอร์มสร้างใบงาน

ลำดับฟิลด์ (บนลงล่าง):

1. **✍️ ผู้สร้างใบงาน** — กล่องพื้น indigo-50 มีขอบ, dropdown + ปุ่ม "+ ชื่อใหม่" · **บังคับ**
2. ชื่องาน · **บังคับ**
3. รายละเอียด
4. ประเภทงาน | ความสำคัญ (+ แสดง "SLA: ภายใน N ชั่วโมง" ใต้ช่อง)
5. Site (datalist จากค่าที่เคยใช้) | ลูกค้า
6. อุปกรณ์ | กำหนดเสร็จ
7. เลขโครงการ *(ไม่บังคับ)*
   - placeholder: `E26-1234`
   - hint: "รูปแบบ E + ปี 2 หลัก + \"-\" + เลข 4 หลัก เช่น E26-1234"
8. **ขั้นตอนการทำงาน** — textarea + dropdown แม่แบบ
   - placeholder: `1. ทำ backup ⏎ 2. ติดตั้งเวอร์ชันใหม่ ⏎ 3. ทดสอบ`
   - hint: "วางรายการที่มีเลขนำหน้าได้เลย ระบบตัด `1.` `-` ให้อัตโนมัติ"
9. ผู้รับผิดชอบ (checkbox chips) — ไม่เลือก = ผู้สร้าง

## 8. ตัวเลือก "ฉันคือ"

- อยู่มุมขวาบน ติดกับปุ่มสร้าง
- เก็บใน `localStorage` key `jc_me`
- ใช้เป็นค่าเริ่มต้นของ: ผู้สร้าง, ผู้เขียนคอมเมนต์, `done_by`, ผู้ log เวลา
- มีตัวเลือก `+ เพิ่มชื่อใหม่…` → prompt → POST `/api/members`

## 9. Dashboard

1. **KPI 4 ใบ:** งานเปิดอยู่ · กำลังดำเนินการ · เกินกำหนด · ปิดแล้ว
2. **กราฟแท่งแนวตั้ง:** ภาระงานรายคน (ผู้รับผิดชอบ)
3. **กราฟแท่งแนวนอน:** จำนวนใบงานที่แต่ละคนสร้าง
4. **ตาราง:** งานเกินกำหนด + ใกล้ครบ (คลิกแถวเปิด modal)
   - คอลัมน์: Code · งาน · **ผู้สร้าง** · ผู้รับผิดชอบ · ความคืบหน้า · กำหนด · สถานะ

## 10. Responsive

| Breakpoint | พฤติกรรม |
|---|---|
| ≥ 1280px | เต็มรูปแบบ |
| 768–1279px | Sidebar ยุบเป็นไอคอน · การ์ดกว้าง 260px |
| < 768px | Sidebar เป็น bottom nav · คอลัมน์เลื่อนแนวนอนทีละใบ (snap) · modal เต็มจอ |

## 11. Toast

- ตำแหน่ง: กลางล่าง · พื้นหลัง `slate-900` · หายเองใน 5 วินาที
- มีปุ่มกระทำได้ 1 ปุ่ม เช่น "ย้ายเลย"
- ใช้กับ: auto-move, apply template, ลบสำเร็จ, error

## 12. Accessibility

1. ทุกปุ่มมี `aria-label` ถ้าไม่มีข้อความ
2. Modal ปิดด้วย `Esc` และคลิกพื้นหลัง
3. Focus ring มองเห็นชัด (`ring-2 ring-indigo-500`)
4. Contrast ratio ≥ 4.5:1 สำหรับข้อความปกติ
